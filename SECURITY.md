# Security

Report security issues through **Report a vulnerability** in the repository's Security tab. Please use the private form for reports that include credentials, private paths, or a proof of concept. [Private vulnerability reporting](https://github.com/yusufserhatozkan/icecs2026-scnn-stm32/security)

The tools run locally. Use trusted checkpoints, ONNX files, and data. Check the bundled artifacts with the verifier in the README and use the current dependencies in the reproduction guide.
